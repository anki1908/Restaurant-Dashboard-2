# 🍽️ Restaurant Sales & Performance Dashboard — Power BI

## 📌 Project Overview

This project presents an **interactive Restaurant Sales & Performance Dashboard built using Microsoft Power BI**. The dashboard analyzes **1,000 restaurant order transactions** and converts raw transactional data into meaningful business insights.

The project demonstrates the complete data analytics workflow, including **data preparation, transformation, calculated fields, DAX measures, data visualization, KPI development, and interactive filtering**.

The dashboard is designed to help restaurant management understand sales performance, customer ordering patterns, menu performance, table revenue, server performance, payment preferences, and peak ordering hours.

---

## 🎯 Business Objective

The primary objective of this project is to analyze restaurant operations and answer important business questions such as:

* What is the total revenue generated by completed orders?
* How many completed orders were processed?
* What is the average order value?
* Which menu items are the most popular?
* Which food categories generate the highest revenue?
* Which tables generate the most revenue?
* Which servers generate the highest sales?
* What are the busiest ordering hours?
* Which payment methods are most commonly used?
* How does restaurant revenue change over time?

## 🧹 Data Preparation

The raw restaurant data was imported into **Power BI using Power Query**.

The data preparation process included:

* Reviewing the raw dataset
* Checking and assigning appropriate data types
* Preparing date and time fields
* Creating calculated columns
* Creating an order-hour field for time-based analysis
* Maintaining cancelled and refunded orders for operational analysis
* Excluding cancelled and refunded transactions from completed-order revenue calculations

---

## 🧮 Calculated Fields

The following calculated fields were created during data preparation:

### Gross Sales

```text
Gross Sales = Quantity × Unit Price
```

### Discount Amount

```text
Discount Amount = Gross Sales × Discount %
```

### Net Sales

```text
Net Sales = Gross Sales − Discount Amount
```

### Tax

A 5% tax rate was used for this project.

```text
Tax = Net Sales × 5%
```

### Final Amount

```text
Final Amount = Net Sales + Tax
```

### Order Hour

The order time was transformed into an hourly value to analyze restaurant demand throughout the day.

---

## 📐 DAX Measures

DAX measures were created to calculate the main business KPIs dynamically.

### Total Revenue

```DAX
Total Revenue =
CALCULATE(
    SUM(Raw_Data[Final_Amount]),
    Raw_Data[Order_Status] = "Completed"
)
```

### Total Orders

```DAX
Total Orders =
CALCULATE(
    DISTINCTCOUNT(Raw_Data[Order_ID]),
    Raw_Data[Order_Status] = "Completed"
)
```

### Average Order Value

```DAX
Average Order Value =
DIVIDE(
    [Total Revenue],
    [Total Orders]
)
```

### Total Items Sold

```DAX
Total Items Sold =
CALCULATE(
    SUM(Raw_Data[Quantity]),
    Raw_Data[Order_Status] = "Completed"
)
```
